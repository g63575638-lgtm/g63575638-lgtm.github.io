# FUTON GOLF VR

**Студия: FUTON GROUP** · VR-гольф для Meta Quest 2 · English version below ↓

FUTON GOLF VR — VR-игра в гольф на собственном движке (WebGL2 + WebXR, ноль внешних зависимостей).
Игра запускается в Meta Quest Browser как иммерсивное WebXR-приложение. Официальным инструментом Meta
(Bubblewrap для Meta Quest) она упаковывается в APK и ставится через SideQuest.

## 2. Самый быстрый запуск (без APK, ~2 минуты)

WebXR работает только в безопасном контексте (HTTPS или `localhost`). Удобнее всего так:

**Вариант 1 — USB-кабель (localhost):**
1. Включите на Quest режим разработчика и подключите шлем к ПК кабелем.
2. На ПК в папке проекта запустите локальный сервер:
   `npx http-server dist -p 8080` (или `python -m http.server 8080 --directory dist`).
3. Пробросьте порт в шлем: `adb reverse tcp:8080 tcp:8080`.
4. В шлеме откройте **Meta Quest Browser** → `http://localhost:8080` → кнопка **ВОЙТИ В VR / ENTER VR**.

**Вариант 2 — любой HTTPS-хостинг:** загрузите содержимое `dist/` на GitHub Pages, Netlify или Cloudflare Pages
и откройте адрес в Quest Browser.

Проверить игру можно и на ПК без шлема: откройте страницу в Chrome или Edge → **ИГРАТЬ НА ПК**.

## 3. APK для SideQuest

### Как это устроено
Meta официально поддерживает упаковку WebXR-игр в APK (PWA / Trusted Web Activity) инструментом
`@meta-quest/bubblewrap-cli`. В режиме `immersive` APK запускается сразу в VR, как нативное приложение.
Игру при этом загружает с вашего HTTPS-адреса, а service worker кэширует её для офлайн-запуска.

Требования Meta:
- игра лежит по **HTTPS**, лучше в **корне домена**;
- по адресу `https://ваш-домен/.well-known/assetlinks.json` лежит файл Digital Asset Links с отпечатком
  ключа подписи. Наши скрипты генерируют его автоматически в `dist/.well-known/`.

> Для GitHub Pages нужен собственный домен (Custom domain) или репозиторий вида `<user>.github.io`.
> У project-сайта `<user>.github.io/<repo>/` папка `.well-known` не лежит в корне домена.

### A. Сборка APK на своём ПК
Нужны Node.js 18+, JDK 17 и интернет (Bubblewrap при первом запуске сам скачает Android SDK).
```bash
./tools/package-apk.sh https://golf.example.com/
```
Скрипт:
1. собирает `dist/`;
2. создаёт ключ подписи `android/android.keystore` (храните его: обновления подписываются тем же ключом);
3. пишет `dist/.well-known/assetlinks.json`;
4. генерирует проект Bubblewrap (`isMetaQuest: true`, `horizonOSAppMode: immersive`);
5. собирает **`FUTON_GOLF_VR.apk`** в корне проекта.

После этого загрузите `dist/` (вместе с `.well-known/`) на хостинг.

### B. Сборка в GitHub Actions
1. Залейте проект в репозиторий GitHub.
2. Settings → Pages → Source: **GitHub Actions**. При необходимости укажите Custom domain.
3. Settings → Variables → `SITE_URL` = `https://ваш-домен/`.
4. По желанию (рекомендуется) добавьте секреты `ANDROID_KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_PASSWORD` для постоянного ключа.
5. Сделайте push. Workflow соберёт игру, прогонит тесты, опубликует сайт и приложит артефакт
   `FUTON_GOLF_VR` с файлами `FUTON_GOLF_VR.apk` и `FUTON_GOLF_VR_SOURCE.zip`.

### Установка через SideQuest
1. Режим разработчика на Quest → подключите шлем к ПК → откройте SideQuest.
2. Перетащите `FUTON_GOLF_VR.apk` в окно SideQuest (или выполните `adb install -r FUTON_GOLF_VR.apk`).
3. В шлеме: Библиотека → **Неизвестные источники** → **FUTON GOLF**.

## 4. Управление (кратко, подробно — в `CONTROLS.md`)

| Действие | Quest-контроллеры |
|---|---|
| Взять / отпустить клюшку | **GRIP** (боковая кнопка) рядом с рукояткой |
| Вернуть клюшку в руку | удерживать **GRIP** пустой рукой ~0.5 с |
| Удар | физический замах: клюшка бьёт мяч при контакте |
| Ходьба | левый стик (клик — бег) |
| Поворот | правый стик влево/вправо (пошаговый или плавный) |
| Телепорт | правый стик вперёд → прицел → отпустить |
| Подойти к мячу | **B** |
| Подсветка мяча | **X** |
| Следующая / предыдущая клюшка | **A** / клик правого стика |
| Меню паузы | **Y** |
| Нажатие в меню | луч контроллера + **курок** |

## 5. Игра

- **Карты.** Три самостоятельные локации, 6 лунок в каждой (пар 23 на каждом поле):
  - **GREEN VALLEY** — холмы, четыре озера, лиственные и хвойные леса, ветряная мельница, клаб-хаус, заснеженные горы на горизонте. По умолчанию полдень.
  - **SUNSET COAST** — лунки на скалах у океана, на лунке 2 удар через морскую бухту, пальмы, пляжи с зонтиками, маяк, яхты. Закат с солнечной дорожкой на воде.
  - **MOUNTAIN RESORT** — альпийская чаша, сосны, гранитные валуны, три горных озера, шале-курорт, канатная дорога. Утро, разреженный воздух: мяч летит дальше.
  - Время суток выбирается отдельно: утро, полдень или закат на любой карте.
- **Режимы.** Строук-плей (6 лунок), Быстрый раунд (лунки 1–3), На время (удары + таймер), Тренировка (без счёта, любая лунка, сброс мяча).
- **Счёт по правилам гольфа.** Удары, пар, итог к пару, карта счёта с обозначениями бёрди и боги.
  Вода: +1 штрафной удар и дроп у места пересечения границы преграды. Аут: удар и расстояние (+1).
  Подъём мяча после 10 ударов на лунке. Личные рекорды сохраняются на устройстве.
- **Интерфейс.** Главное меню на фоне 3D-поля. HUD на запястье: лунка, пар, удары, итог, расстояние до флага, клюшка, лежка, ветер, таймер. Табличка на ти с картой лунки. Маркер флага с расстоянием. Всплывающие сообщения, пауза, настройки.
- **Языки.** Русский и английский: весь интерфейс, подсказки и сообщения. Переключение в настройках и на стартовом экране.

## 6. Физика

- **Удар.** Непрерывная (swept) коллизия головки клюшки с мячом с интерполяцией внутри кадра, без «проскакивания» даже на 50 м/с.
  В расчёт идут скорость головки (позы XR и конечные разности), её траектория, угол лица, динамический лофт, точка контакта, удар носком/пяткой (gear effect), «жирный» удар по земле и лежка (раф, бункер, ти).
  Модель удара: косой удар лофтированной поверхностью, COR и эффективная масса головки, обратное и боковое вращение из касательной составляющей.
- **Полёт.** Гравитация, сопротивление с «кризисом сопротивления», подъёмная сила Магнуса Cl(S), затухание вращения, ветер с ростом по высоте, плотность воздуха по карте.
- **Земля.** Импульсная модель отскока: восстановление и трение в точке контакта с учётом вращения, поэтому мяч с обратным вращением «останавливается» или откатывается назад на грине.
  Переход от проскальзывания к качению, сопротивление качению по покрытиям, ускорение катящегося шара на склоне 5/7·g·sinθ, отрыв на гребнях, неровности рафа.
- **Лунка.** Реальная геометрия: кромка, стенки и дно. Мяч на скорости может «облизать» лунку и выскочить. Флагшток на подлёте, автоматически вынимается, когда мяч на грине.
- **Препятствия.** Стволы, кроны (ветки отбивают мяч), валуны, вода, аут.
- **Проверка цифрами** (`node tests/phys_test.js`, ровный фервей):

  | Клюшка | Скорость головки | Скорость мяча | Вылет | Вращение | Полёт |
  |---|---|---|---|---|---|
  | Драйвер | 45 м/с | 64.7 м/с | 11.0° | 2 500 об/мин | 203 м |
  | 7 железо | 35 м/с | 46.0 м/с | 18.9° | 5 400 об/мин | 139 м |
  | PW | 32 м/с | 36.8 м/с | 26.6° | 6 700 об/мин | 102 м |

  Скорость грина соответствует стимпметру ≈ 9.6. Мяч ловится лункой при скорости до ≈ 1.5 м/с в центр
  (реальные данные — ≈ 1.6 м/с), при смещении меньше.

## 7. Графика и оптимизация под Quest 2

- Стилизованная полуреалистичная картинка: процедурные модели с запечённым AO, линейное освещение, ACES-тонмаппинг,
  каскадные тени (2 каскада, PCF), небо с объёмными облаками, туман воздушной перспективы, вода с френелем,
  отражением неба, бликами солнца и пеной у берега, трава с ветром и примятием у мяча, полосы стрижки на фервеях.
- Оптимизация:
  - ландшафт из 256 чанков с 5 уровнями LOD и «юбками»;
  - инстансинг растительности с тремя LOD деревьев и упрощёнными прокси для теней;
  - процедурная трава на GPU, сетка смещена вперёд по взгляду;
  - дальние тени деревьев запечены в ландшафт;
  - отсечение по конусу взгляда, фиксированная фовеация, выбор частоты 72 / 80 / 90 Гц, масштаб разрешения;
  - автоматическое снижение детализации, если FPS проседает.
- Бюджет (замер в профайлере): ≈ 280–390 тыс. треугольников на вид при «Баланс», включая тени.

```
src/00_math.js      векторы, матрицы, кватернионы, шум, RNG

src/04_geometry.js  процедурные модели: мяч с лунками, 9 клюшек, флаг, деревья, постройки
src/05_terrain.js   генерация поля: рельеф, покрытия, озёра, растительность, LOD-рендер ландшафта

src/07_physics.js   физика мяча и модель удара клюшкой
src/08_audio.js     процедурный пространственный звук (HRTF)
src/09_ui.js        VR-интерфейс: панели, виджеты, лучи, логотип FUTON GROUP
src/10_world.js     рендер мира: тени, растительность, вода, небо, частицы, трассер мяча
src/11_club.js      клюшка как физический VR-объект: хват, бросок, отзыв, коллизия удара
src/12_player.js    ввод WebXR, передвижение, телепорт, комфорт, режим ПК
src/13_game.js      игровая логика: режимы, счёт, лунки, меню, HUD
src/14_main.js      WebXR-сессия, цикл рендеринга, стартовый экран
```

Сборка: `node tools/build.js` → `dist/index.html`.
