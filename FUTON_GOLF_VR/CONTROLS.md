# FUTON GOLF VR — Управление / Controls

## Meta Quest 2 (VR)

| | Действие | Action |
|---|---|---|
| **GRIP** (боковая кнопка) у рукоятки | Взять клюшку. Отпустить GRIP — бросить или положить её | Grab the club. Release GRIP to drop or throw it |
| Удерживать **GRIP** пустой рукой | Клюшка прилетает в руку | Recall the club to your hand |
| Физический замах | Удар происходит только при контакте головки с мячом | The hit happens only when the club head touches the ball |
| **Левый стик** | Ходьба по направлению взгляда (клик — бег) | Walk where you look (click = run) |
| **Правый стик** ← → | Поворот (пошаговый или плавный — в настройках) | Turn (snap or smooth — see settings) |
| **Правый стик** вперёд | Прицел телепорта (дуга). Отпустить — переместиться | Aim teleport arc, release to teleport |
| **B** | Встать к мячу в стойку, лицом к цели | Stand at address next to your ball |
| **X** | Подсветка мяча: свечение, кольцо и световой столб | Ball finder: glow, ring and light pillar |
| **A** | Следующая клюшка | Next club |
| Клик **правого стика** | Предыдущая клюшка | Previous club |
| **Y** | Меню паузы | Pause menu |
| Луч + **курок** | Нажатие кнопок меню, ползунки | Press menu buttons, drag sliders |
| Тренировка: **курок + B** | Вернуть мяч на ти | Practice: reset the ball to the tee |

Для левши выберите Настройки → Игра → Игрок: **Левша**. Стики поменяются местами, клюшка развернётся.

### Советы по удару / Swing tips
- Держите контроллер как рукоять клюшки: кольцо направлено к мячу. Если клюшка «торчит» под неудобным углом,
  измените **Угол клюшки** (Настройки → Игра).
- Сила удара зависит от реальной скорости головки клюшки. Короткий плавный замах даёт короткий удар, полный — длинный.
  Если играете в тесной комнате, включите **Усиление удара** (+10…35 %).
- Открытое лицо клюшки уводит мяч вправо (фейд/слайс), закрытое — влево (дро/хук) у правши.
  Удар носком даёт хук-вращение, пяткой — слайс-вращение.
- Задели землю перед мячом — «жирный» удар: мяч летит заметно короче.
- Из бункера бейте SW или PW. Из рафа мяч летит короче и с меньшим вращением.
- **Безопасность:** освободите пространство вокруг себя. Замах контроллером — реальное движение руки.

## Desktop / ПК (preview & testing)

| Key | Action |
|---|---|
| W A S D | Move |
| Right mouse | Lock mouse look (Esc to release) |
| Hold left mouse, drag up, then sharply down | Backswing, then downswing through the ball |
| 1–9 | Select club (DR, 3W, 4H, 5i, 7i, 9i, PW, SW, PT) |
| B / F | Go to ball / ball finder |
| Q / E | Turn |
| Esc | Pause menu |
| Mouse click | Press menu buttons |
